# Folia 模组：QQ 音乐猜你喜欢个性化推荐 (QQ Music Guess-You-Like Mod)

![QQ 音乐猜你喜欢个性化推荐](preview.jpg)

为 [Folia 音乐播放器](https://github.com/chthollyphile/folia-major) 的 QQ 音乐音源接入真正的**「猜你喜欢」个性化推荐流**。

基于 Folium 模组系统设计，无需重新编译播放器即可通过热插拔方式运行。

---

## 🌟 模组特性

1. **真实专属个性化流**：自动识别已登录账号的 QQ 音乐鉴权凭据，直连腾讯官方个性化算法网关（电台 ID `99` 猜你喜欢），让推荐真正契合你的听歌品味。
2. **平滑优雅降级机制**：若用户未登录 QQ 音乐或凭证失效，自动无感降级至官方公开的随心听（`101`）与热歌（`199`）电台流，任何状态下皆可流畅播放。
3. **首曲封面自动提取**：自动提取曲目流第 1 首歌曲的高清专辑大图（`https://y.gtimg.cn/music/photo_new/T002R300x300M000...`），解决电台入口无固定封面导致的空白问题。
4. **曲目规格严谨对齐**：输出与宿主 `normalizeQqSong` 一致的统一曲目结构（包含完整的 `songId`、`songMid`、`albumMid`、`mediaMid` 等 provider 契约字段），保证播放、歌词与收藏功能正常运作。
5. **安全与纯净卸载**：模组退出时完整还原宿主内部状态与能力标记，不留脏状态。

---

## 🔍 技术实现与安全性说明

本模组通过 `folium.internals` 为内置 QQ 音乐音源补充推荐流能力：
- **改写能力标记**：在激活时将 `omni.getProviderCapabilities('qq').recommendations` 设为 `true`，卸载时精准还原回原值。
- **劫持内部函数**：替换 `omni.getPersonalFm`，在当前音源为 QQ 音乐时拉取电台 99 个性化流，卸载时恢复为原始引用。
- **兼容版本范围**：钉住在实际测试验证过的版本范围 `folia: ">=0.7.17 <0.8.0"`。
- **登录凭证与安全隐私承诺**：
  - 本模组通过读取宿主本地属于 QQ 音乐的存储项（`online_provider:qq:cookie`）获取用户登录态；
  - **凭据使用范围严格受限**：所有凭据仅直接通过 `net.fetch` 发往腾讯官方网关（`https://u.y.qq.com/cgi-bin/musicu.fcg`），用于向电台 99 请求个性化推荐曲目；
  - **绝不外泄**：本模组绝不设立任何中转服务、绝不上传任何凭据至任何第三方服务器、绝不执行远程动态代码，代码 100% 透明开源并接受安全审计。

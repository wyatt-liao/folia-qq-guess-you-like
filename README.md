# Folia 模组：QQ 音乐电台推荐增强 (QQ Music Radio Mod)

![QQ 音乐电台推荐增强](preview.jpg)

为 [Folia 音乐播放器](https://github.com/chthollyphile/folia-major) 的 QQ 音乐音源接入**「随心听」公共电台流**。

基于 Folium 模组系统设计，无需重新编译播放器即可通过热插拔方式运行。

---

## 🌟 模组特性

1. **随心听电台流接入**：调用 QQ 音乐官方公开电台接口（电台 ID `101` 随心听，自动降级至 `199` 热歌），在电台页呈现可直接播放的电台音频流。
2. **首曲封面自动提取**：自动提取曲目流第 1 首歌曲的高清专辑大图（`https://y.gtimg.cn/music/photo_new/T002R300x300M000...`），解决电台入口无固定封面导致的空白问题。
3. **曲目规格严谨对齐**：输出与宿主 `normalizeQqSong` 一致的统一曲目结构（包含完整的 `songId`、`songMid`、`albumMid`、`mediaMid` 等 provider 契约字段），保证播放、歌词与收藏功能正常运作。
4. **安全与纯净卸载**：模组退出时完整还原宿主内部状态与能力标记，不留脏状态。

---

## 🔍 技术实现与内部状态说明

本模组通过 `folium.internals` 为内置 QQ 音乐音源补充推荐流能力：
- **改写能力标记**：在激活时将 `omni.getProviderCapabilities('qq').recommendations` 设为 `true`，卸载时精准还原回原值。
- **劫持内部函数**：替换 `omni.getPersonalFm`，在当前音源为 QQ 音乐时拉取公开电台流，卸载时恢复为原始引用。
- **兼容版本范围**：钉住在实际测试验证过的版本范围 `folia: ">=0.7.17 <0.8.0"`。
- **关于个性化推荐的说明**：由于本模组仅通过公开主进程网络请求公共电台，不读取也不涉及用户的登录凭据，因此提供的是公共「随心听 / 热歌」精选电台流，而非需要登录态的私人个性化流。

---

## 🔒 权限说明

- **`net.fetch`**：用于向腾讯官方接口（`https://u.y.qq.com/cgi-bin/musicu.fcg`）请求公开电台歌曲列表。本模组不收集、不上传任何用户数据，不执行任何远程代码。

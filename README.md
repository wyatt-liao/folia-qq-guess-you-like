# Folia 模组：QQ 音乐雷达电台与随心听 (QQ Music Radar & Stream Mod)

![QQ 音乐雷达电台与随心听](preview.jpg)

为 [Folia 音乐播放器](https://github.com/chthollyphile/folia-major) 的 QQ 音乐音源接入**「随心听」**与 **11 款精选热门雷达电台矩阵**。

基于 Folium 模组系统设计，无需重新编译播放器即可通过热插拔方式运行。

---

## 🌟 模组特性

1. **官方公开电台流**：匿名请求腾讯官方公开电台接口（电台 ID `101` 随心听，若空自动回退至 `199` 热歌），即点即播，流畅播放。
2. **首曲封面自动提取**：推荐曲目流第 1 首歌曲自带高清专辑大图，由宿主自动提取展示，告别灰色黑胶默认唱片或空白卡片。
3. **11 款精选热门雷达电台矩阵**：同步引入 QQ 音乐 11 个经典热门频道，各频道采用静态高清专辑封面，首屏秒级加载且零额外网络并发：
   - 随心听（`101`）
   - 热歌电台（`199`）
   - 流行音乐（`345`）
   - 情感治愈站（`673`）
   - 经典情歌（`550`）
   - 快乐节拍（`140`）
   - 热血摇滚（`130`）
   - 中国风韵（`190`）
   - 精选招牌歌（`307`）
   - 跑步模式（`100`）
   - 网络流行（`167`）
4. **电台卡片直接打开播放**：接管 `omni.getCollectionTracks`，点击任意电台卡片即可直接拉取 30 首实时曲目并开始播放。（注：电台曲目会被宿主集合缓存机制保存，短期内重复打开相同电台为一致列表）。
5. **曲目规格严谨对齐**：完全依照宿主 `normalizeQqSong` 契约构造 UnifiedSong 对象（数字 `songId`、完整 `providerData`，无多余 fallback 字段），保证播放流解析、歌词联动与收藏交互均完全正常。
6. **安全与纯净卸载**：模组退出时 100% 完整还原所替换的宿主内部函数与能力标记，不留脏状态。

---

## 🔍 技术实现与安全性说明

本模组通过 `folium.internals` 为内置 QQ 音乐音源补充电台与推荐能力：
- **改写能力标记**：在激活时将 `omni.getProviderCapabilities('qq').recommendations` 设为 `true`，卸载时精准还原回原值。
- **替换内部函数**：替换 `omni.getPersonalFm`、`omni.getHomeFeed`、`omni.getCollectionTracks`，卸载时恢复为原始引用。
- **兼容版本范围**：严格钉住在实际测试通过的版本范围 `folia: ">=0.7.17 <0.8.0"`。
- **纯净安全承诺**：本模组所有网络请求均通过 `folium.net.fetch` 直连腾讯官方公开接口（`https://u.y.qq.com/cgi-bin/musicu.fcg`），**不读取任何本地凭证、不发送任何 Cookie、不设立中转服务、不收集任何用户隐私、不执行远程代码**，完全开放源代码接受安全审查。

# Folia 模组：QQ 音乐猜你喜欢与雷达电台 (QQ Music Guess-You-Like & Radar Mod)

![QQ 音乐猜你喜欢与雷达电台](preview.jpg)

为 [Folia 音乐播放器](https://github.com/chthollyphile/folia-major) 的 QQ 音乐音源接入**「猜你喜欢」**个性化推荐流与 **11 款精选热门雷达电台矩阵**。

基于 Folium 模组系统设计，无需重新编译播放器即可通过热插拔方式即插即用。

---

## 🌟 模组特性

1. **猜你喜欢专属流**：无缝对接 QQ 音乐个性化推荐（电台 ID `99`），支持未登录状态平滑降级（自动回退到随心听或热歌），确保任何状态下皆可流畅播放。
2. **首曲封面自动提取**：针对“猜你喜欢”本身无固定封面的特性，自动抓取推荐曲目流第 1 首歌曲的专辑大图（`T002R300x300M000...`），告别空白灰阶图标。
3. **2×2 核心英雄大卡片**：将“猜你喜欢”作为雷达页面最醒目的核心按钮，享受 2×2 大尺寸焦点与动态声波/雷达光晕。
4. **精选雷达电台矩阵**：同步引入 QQ 音乐网页版雷达页面的 11 个经典热门频道，每个频道并发拉取第一首歌作为电台专属封面：
   - 随心听（`101`）
   - 热歌电台（`199`）
   - 流行音乐（`345`）
   - 情感治愈站（`673`）
   - 经典情歌（`550`）
   - 快乐节拍（`140`）
   - 热血摇滚（`130`）
   - 中国风韵（`190`）
   - 精选招牌歌（`307`）
   - 跑步模式（`100`）
   - 网络流行（`167`）

## 🚀 安装与使用

### 方法一：通过 Folium 模组市场一键安装（推荐）
在 Folia 的模组市场中搜索 **`QQ音乐猜你喜欢与雷达电台`** 或 `qq-guess-you-like`，点击安装即可。

### 方法二：手动安装
1. 下载本仓库的代码压缩包或克隆本仓库；
2. 将目录命名为 `qq-guess-you-like` 并放入 Folia 的 `mods/` 文件夹下；
3. 打开 Folia 并在设置中启用该模组，切换至“电台”页签即可体验。
